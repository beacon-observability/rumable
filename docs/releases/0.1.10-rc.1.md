# v0.1.10-rc.1

Release candidate for testing before v0.1.10. Stable downloads and configuration pages remain on v0.1.9.

## Changes

- Fix [#4](https://github.com/beacon-observability/rumable/issues/4): empty application pool OTel environment snapshots no longer report false drift or block enable and rollback. Snapshot comparison, equality checks, and environment restoration enumerate object properties explicitly while preserving dictionary and case-sensitive value checks.
- Add regression tests for empty/nonempty JSON and dictionary snapshots, changed keys and values, restoration, idempotency, and preservation of unrelated pool settings. CI checks Windows PowerShell 5.1 and PowerShell 7.
- Include the multilingual setup interface merged after v0.1.9: English, Simplified Chinese, Traditional Chinese, Indonesian, Japanese, and Korean.

## Download and validation

Use the version-pinned assets on this prerelease. The same ten Linux/Windows modern/legacy archives, installers, manifest, SDK metadata, and SHA256SUMS are built and verified by the release workflow. See [platform compatibility](../compatibility.md) before choosing a package.

This RC does not deploy configuration pages or change stable latest aliases. Use the downloaded CLI or installers for isolated validation. It does not migrate or automatically recover existing deployments; use the ordinary recovery/rollback commands with the patched CLI and retain deployment state backups.

PowerShell contract checks use IIS test doubles. Real Windows/IIS enable, recovery, and browser-to-server trace correlation still require native acceptance. The separate managed-agent `dependency ownership mismatch` observation in #4 is not resolved by this RC; explicit `agentPath` isolates that issue.
