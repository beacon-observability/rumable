# Rumable 0.1.9

Rumable joins Beacon Observability while retaining the `rumable` command, configuration schema, bundled SDK, collection behavior, and Nginx/IIS integration.

- Publish Linux and Windows executable packages, installation scripts, manifests, SDK metadata, and checksums through [GitHub Releases](https://github.com/beacon-observability/rumable/releases/tag/v0.1.9).
- Provide an [English configuration page](https://beacon-observability.github.io/rumable/0.1.9/setup/index.html) on GitHub Pages. Generated commands download from the fixed `v0.1.9` GitHub Release and installers verify archive SHA256 hashes.
- Keep compatibility with existing manifests and publication workflows. Cached installers downloaded through GitHub's latest URL resolve archives to their embedded version.
- Standardize public documentation, examples, demo pages, and setup interface in English.
- Add GitHub CI and a release workflow with dual-compiler validation, Linux Nginx integration checks, Windows package execution, installer/IIS contracts, draft upload verification, and anonymous public-download verification.

Modern builds use Go 1.26.4. Legacy x86/x64 builds use Go 1.20.14 and retain the limitations documented in [platform compatibility](../compatibility.md). This release workflow checks Windows AMD64 executables on Windows Server 2022; older Windows and production IIS layouts still require their own acceptance.

See the [user guide](../../USER-GUIDE.md) for installation and recovery, and the [release guide](../github-release.md) for publication and retry procedures. Upgrading the CLI does not upgrade or rewrite an existing site's configuration automatically. Keep existing state and backups, extract the new executable into a separate versioned directory, and use the documented setup/probe workflow before changing production traffic.
