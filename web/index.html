01

连接你的应用

使用应用管理中创建的 RUM 应用信息。

02

选择 SDK 来源与加载方式

服务器在 HTML 中加入脚本，浏览器按所选方式加载并初始化 SDK。

SDK 随 Rumable 安装包提供，由你的网站同域托管；浏览器无需访问外部 CDN。

跨域 SRI 需要 CDN 允许 CORS。官方 v3 地址默认关闭此项；自建固定版本地址可开启，安装时会检查。

初始化脚本和 SDK 均异步加载，下载不阻塞 HTML 解析；初始化完成前的错误、请求和交互可能无法采集。

SDK 如何更新

同域 SDK 固定在安装包版本。安装新版 Rumable 后，需对原站点重新执行接入命令或 enable 才会升级；仅下载或替换程序不会更新站点。保留旧资源以便回滚。

“应用版本”用于标记业务版本，“SDK 远程配置”用于调整采集参数，两者都不会升级 SDK 文件。

03

决定采集什么

性能、资源和错误由 SDK 自动采集，以下控制采样与录制。

先采样 RUM 会话，再决定是否录制。回放需要站点 CSP 允许相应 Worker。

高级 Web SDK 配置

远程配置可能覆盖静态参数。setUser、自定义 startView、beforeSend 等需要业务调用，不通过服务器注入自动实现。

04

选择安装环境

网站信息由安装命令在服务器上自动发现。

需要 Bash、curl 和 sudo；安装时自动识别 Linux x86（32 位）/ x64 / ARM64 架构。

只有一个站点时自动选择；多个站点或访问地址时在终端选择。无法确定域名时，命令会提示输入网站地址。默认接入所选站点或应用的全部路径。

高级接入设置（可选）

未勾选时，自动发现流程会在需要调整时询问。停用或卸载接入会恢复原设置。

页面需含标准 <head> 开始标签。部署会检查 CSP、SDK 冲突和验收页面；不兼容时停止并保留恢复记录。

IIS 需要 URL Rewrite 和静态资源读取权限。以管理员身份运行 PowerShell 5.1+，安装器自动识别 x64 / ARM64 和 Windows 版本，旧系统自动选择 legacy 包；32 位 Windows 不支持 IIS 一键接入。
