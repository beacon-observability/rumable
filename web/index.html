02

Choose how to load the SDK

The server injects scripts into HTML. The browser loads and initializes the SDK using your selected method.

The SDK is bundled with Rumable and served from your website's origin. Browsers do not need an external CDN.

With SRI enabled, browsers reject files that do not match the digest saved at activation. Prefer an immutable URL. The CDN must allow cross-origin access (CORS).

Asynchronous loading does not block HTML parsing. Errors, requests and interactions before initialization may not be captured.

How SDK updates work

After updating Rumable, run setup or enable again for the original site to update the SDK. Replacing the program alone has no effect. Keep old assets for rollback.

Application version and SDK remote configuration do not update SDK files.

03

Choose what to collect

The SDK automatically collects performance, resource and error data. Configure sampling and recording below.

RUM sessions are sampled before replay recording is selected. Your site's CSP must allow the required Worker.

Advanced Web SDK settings

Remote configuration may override static settings. setUser, custom startView and beforeSend require application code and are not implemented by server injection.

04

Choose your server environment

The installation command discovers websites on your server.

Requires Linux Nginx 1.9.4+, http_sub_module, Bash and curl. Run as root or with sudo. Applying setup changes reloads Nginx.

A single site is selected automatically. Choose in the terminal if multiple sites or URLs are found; enter the website URL if its domain cannot be identified. All paths in the selected site or application are included by default.

Advanced setup (optional)

If unchecked, discovery asks for permission when changes are needed. Disabling or uninstalling restores the original settings.

Automatic injection only supports <head> tags.

Requires 64-bit Windows, IIS 7.5+, URL Rewrite 2.x, static resource read access and a dedicated application pool. Run PowerShell 5.1+ as administrator. Enabling, disabling, updating and rolling back recycle the pool and may lose in-process sessions.
