03

选择安装环境

网站信息由安装命令在服务器上自动发现。

需要 Bash、curl 和 sudo；安装时自动识别 Linux x86（32 位）/ x64 / ARM64 架构。

只有一个站点时自动选择；多个站点或访问地址时在终端选择。无法确定域名时，命令会提示输入网站地址。默认接入所选站点或应用的全部路径。

高级接入设置（可选）

未勾选时，自动发现流程会在需要调整时询问。卸载接入会恢复原设置。

页面需含标准 <head> 开始标签。部署会检查 CSP、SDK 冲突和验收页面；不兼容时停止并保留恢复记录。

IIS 需要 URL Rewrite 和静态资源读取权限。以管理员身份运行 PowerShell 5.1+，安装器自动识别 x64 / ARM64 和 Windows 版本，旧系统自动选择 legacy 包；32 位 Windows 不支持 IIS 一键接入。
